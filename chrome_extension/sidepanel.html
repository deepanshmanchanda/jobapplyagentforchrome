Open an application page to begin.

Work in this tab

Autopilot uses the model to assess the current page, choose supported actions, and draft answers from your saved facts. It checks the page again after actions that change the form.

New accounts use your saved email and a unique password encrypted on this Windows computer. Verification and required terms may need your attention.

Add a missing answer

Give an answer or describe what to change, for example Only add my engineering degree, not my postgraduate diploma. The agent interprets the request using your saved education records before changing fields. It shows what it understood and asks when the request is unclear. With Remember checked, supported education choices are saved for this employer's site.

Autopilot reuses browser sign-ins. If a sign-in or verification needs attention, complete it on the application page, then continue.
